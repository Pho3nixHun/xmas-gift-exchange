# Retained village prototype artwork

These assets support the retained illustrated fallback and the chosen visual direction. The 3D house constructs its geometry procedurally and does not use these images as scenery. Rejected letter/baking artwork has been removed.

Generated with the built-in image generation tool using the imagegen skill. Selected outputs are copied into this project; no asset depends on the generator’s cache directory.
